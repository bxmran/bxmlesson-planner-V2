# Bxmlesson Planner V2

上传教学进度表，生成指定或全部课次的完整、可编辑 Word 教案。

## 安装

在支持从 GitHub 导入 Skill 的 AI 工作环境中，可以尝试发送：

```text
请帮我安装这个 Skill：https://github.com/bxmran/bxmlesson-planner-V2
```

如果当前 AI 不支持直接读取 GitHub 并安装 Skill，请从仓库下载 ZIP，再通过该平台的技能管理功能导入。不同平台的导入方式和能力可能不同。

## 使用

安装后上传教学进度计划表，并发送：

```text
使用 bxmlesson-planner V2，按我上传的进度表生成第1—16次课的完整教案，只给我一个 Word 文件。
```

也可以指定其他课次范围，或说“按计划表全部生成”。课次数量不固定，但受宿主环境的上下文、文件处理和执行能力限制。

## 运行要求

完整工作流需要宿主能够读取 Word、执行 Python 3，并安装 `python-docx`。核心入口是 `SKILL.md`；规则位于 `references/`，程序位于 `scripts/`，内置模板位于 `assets/`，测试位于 `tests/`。

本地测试命令：

```bash
python -m unittest discover -s tests -v
```

普通授课课次设有逐课正文硬性下限（4,500个去空白字符），并同时检查总字数上限、必填字段、课次/学时/作业一致性及课堂时间；校验报告会列出逐课字数。多课次任务建议内部按每批2—4次课撰写后合并。若宿主不能运行 Python 脚本，不能保证自动套用学校 Word 模板及执行程序校验。

仓库内置学校版式及标识。公开分发前，请确认拥有相应使用和传播授权。教学进度表由使用者自行上传，不随仓库发布。
